## 起動と配信

1. `dist/YuiTracking/YuiTracking.exe` を起動します。フォルダ内のDLL・Assetsは移動せず、フォルダごと保管してください。
2. 「VRMファイルを開く」でVRM 0.x / 1.0モデルを選ぶか、内蔵ロボットで出力を試します。
3. 実Webカメラを接続して「カメラを開始」。正面を向き、キャリブレーションします。
4. 「仮想カメラ出力を開始」を押します。初回は現在のWindowsユーザーにデバイスを登録します。管理者権限は不要です。出力のオン・オフは保存され、次回起動時に復元されます。
5. OBSのソース追加 → **映像キャプチャデバイス** → **YuiTracking Camera**。1280×720、60fpsを指定します。OBSの設定 → 映像のFPSも60にしてください。登録直後に一覧へ出なければOBSを再起動してください。
6. 緑背景を抜くには、OBSのこのソースに「クロマキー」フィルターを追加します。

プレビューをダブルクリックするとウィンドウ内いっぱいに表示し、もう一度ダブルクリックすると元の配置に戻ります。カメラ認識中は、OBSなど他のアプリが前面でも右Ctrlまたは右Shiftを単独で押して離すと正面位置をキャリブレーションできます。右Ctrl・右Shiftを使うキーの組み合わせでは実行せず、他のアプリのキー入力もそのまま通します。

配信中はアプリを起動したままにしてください。OBSの「仮想カメラ開始」は必要ありません。

### 起動時のVRM

`%LOCALAPPDATA%/YuiTracking/settings.json` の `defaultVrmPath` に指定したVRMを、描画エンジンの準備後に自動で読み込みます。

```json
{
  "defaultVrmPath": "D:\\Avatars\\avatar.vrm"
}
```

ファイル選択で別のVRMを正常に読み込むと、このパスを自動更新し、サンプルの起動設定を解除します。読み込み失敗時は前の設定を維持します。ファイルが移動・削除された場合はエラーを表示し、別のVRMを選び直せます。「サンプル」の各ボタンで選択すると `defaultSample` に `Y`・`Z`・`robot` を保存し、次回はそのサンプルを表示します。最後に開いた個人用VRMのパスは保持します。起動設定がない場合はYを表示します。

## 出力の分離

- 実写入力のvideo要素は画面に配置せず、認識器だけに渡します。画面・デスクトップのキャプチャAPIは使用しません。
- 仮想カメラには、3D描画用canvasからのRGBAフレームだけを送ります。操作画面やファイル選択ダイアログは含みません。
- 「緊急待機画面」はネイティブ送信側でも強制されます。通常の描画停止から約700msで待機画像へ切り替えます。
- 認識データが500ms以上古くなった場合、アバターは待機ポーズへ戻ります。
- 実Webカメラと音声は自動開始しません。仮想カメラ出力は前回のオン・オフを復元します。認識モデルは同梱し、通常利用でクラウドへの映像送信は行いません。
- アプリ自体が強制終了した場合の表示はDirectShowフィルター側に依存します。Windows/OBS停止・競合まで保証するものではありません。

## 現在の範囲と制限

VRM読み込み、顔の回転、まばたき、口・笑顔、上半身の傾き・ひねり、手の位置による腕の簡易IK、手のひらの向き、親指を含む各指の3D関節方向、滑らかさ・感度調整、背景切替、仮想カメラ出力を実装しています。モデルの表情・ボーン構成によって結果は変わります。全身トラッキング、精密な肩・肘の推定、演出・小物・シーン編集は未実装です。

手は肩が映っている場合に肩幅・肩の中心を基準に位置を合わせ、見えない場合は画面内の位置で補います。手のひらと指の各関節がカメラに映るようにしてください。指の重なりや画面外の手は認識が不安定になります。

上半身はカメラを開始すると自動で認識します。肩と胴体を映し、自然な正面姿勢でキャリブレーションしてください。腰まで映ると前後の傾きも読み取りやすくなります。肩が見えなくなると胴体は待機姿勢へ戻ります。顔の回転と胴体の回転が重ならないよう補正しています。姿勢認識は約10回/秒で実行し、描画側で滑らかに補間します。

入力カメラは1280×720・最大30fpsを希望して取得します。カメラが選んだ実際の解像度・FPSをトラッキング欄に表示します。

720p最大60fpsで描画・出力します。顔・手・体の認識は別スレッドで行い、認識結果へ滑らかに追従します。認識の更新頻度は描画FPSとは異なり、実速度はPCとモデルに依存します。録画・配信前にOBSプレビューで確認してください。認識用Webカメラと仮想カメラを同じデバイスにしないでください。

VRMは200MB以下で、画像等を内包したファイルに対応します。外部URLを参照するモデルは許可しません。WebView2 Runtimeが必要です。この開発PCには既に導入されています。

## 開発・検証

`.NET SDK 8` とNode.jsを使用します。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
```

初回の依存取得・認識モデル取得時にはインターネット接続が必要です。

ソース構成:

- `src/YuiTracking.App/`: WinUI 3 GUI、ローカルリソース配信、仮想カメラ送信
- `renderer/src/`: VRM描画・認識・簡易リグ制御
- `tests/CameraSmoke/`: フレーム転送、停止・待機・上下方向などのテスト
- `renderer/tests/`: 関節角度・データ期限・平滑化のテスト

実施済み検証: Windows Releaseビルド、ネイティブGUI起動、VRM読み込み、DirectShowデバイス列挙と1280×720画像受信、認識エンジン初期化、仮想入力の拒否、送信停止時の待機処理。実Webカメラによる顔・手の追従品質と長時間配信は未検証です。

仮想カメラの登録解除: `scripts/unregister-camera.ps1`。YuiTracking専用のユーザー登録のみ解除します。ログは `%LOCALAPPDATA%/YuiTracking/app.log` にあります。
