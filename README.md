# YuiTracking

WebカメラでVRMアバターの顔・目線・上半身・手・指を動かし、OBSへ映像を出力するWindows・Mac向けのトラッキングアプリです。認識は端末内で行います。

## はじめに

1. Windowsではインストーラーを実行します。MacではDMGを開き、YuiTrackingをアプリケーションフォルダーへコピーします。
2. 起動して「VRMを開く」でVRM 0.x／1.0ファイルを選びます。同梱の女の子・男の子・ロボットでも試せます。
3. Webカメラを選び、「カメラを開始」を押します。カメラはアプリ起動時には自動で開始しません。
4. 正面を向いて目を開け、カメラを見てキャリブレーションします。開始後に一度、自動調整も行います。
5. 必要に応じて「動きの調整」で感度・滑らかさを調整し、OBSへ出力します。

Windows版は現在のユーザー用にインストールされます。WebView2 Runtimeがない場合は、インストーラーでの取得にインターネット接続が必要です。現在のWindows配布ファイルにはコード署名を付けていません。Mac版はアドホック署名で、Developer ID署名・Apple公証は付けていません。

## OBSへの出力

### Windows：仮想カメラ

1. YuiTrackingで「仮想カメラ出力を開始」を押します。
2. OBSに「映像キャプチャデバイス」を追加し、デバイスで **YuiTracking Camera** を選びます。
3. 解像度を1280×720、FPSを60に設定します。緑背景を抜く場合はクロマキーフィルターを追加します。

透過背景を使う場合は、OBS側で映像フォーマットをARGB、解像度を1280×720に設定します。登録後に候補が出なければ、OBSのデバイス一覧を開き直してください。

### Mac：Syphon

1. YuiTrackingで「Syphon出力を開始」を押します。
2. OBSの「Syphonクライアント」（Syphon Client／Syphon Source）で、送信元 **YuiTracking** を選びます。

Mac版はWeb会議アプリ等で選ぶ仮想カメラへの出力には対応していません。詳細は [Mac版の説明](electron/README.md) を参照してください。

どちらのOSでも、配信中はYuiTrackingを起動したままにしてください。出力はアバターと背景の映像で、操作画面・ファイル選択ダイアログ・実写カメラ映像は含みません。出力は1280×720・最大60fpsで、実際の速度はPCやモデルの負荷によって変わります。

## 主な機能

- VRM 0.x／1.0の読み込み、同梱サンプル、前回開いたモデルと設定の復元
- 顔の向き、まばたき、口・笑顔、瞳の動きへの追従
- 頭に連動した体のひねり、前後の移動による前傾・反り、離席時の待機姿勢
- 手・指・肘の追従と、認識が途切れたときの待機姿勢への移行
- 顔・体・前傾・反り・口・滑らかさの調整
- モデルに設定された髪・服等の揺れと、対応モデルの胸専用の揺れの調整
- 背景の透過・単色・画像切り替え、表示位置の移動・回転・ズーム
- 認識に使うCPU／GPUの選択
- 配信映像を待機画面に切り替える「待機画面」ボタン

### 目線

「自分の目に追従」「常にカメラ目線」「正面固定」を切り替えられます。目ボーンまたは目線表情に対応したVRMが必要です。

- **目線の追従感度**：自分の瞳の動きを反映する強さです。「自分の目に追従」のときだけ調整できます。
- **目の可動範囲**：モデル標準の1倍から5倍まで拡大できます。「常にカメラ目線」でも使え、1倍に戻すと元の範囲へ戻ります。VRMファイル自体は変更しません。

可動範囲の拡大は、目ボーンでは各方向最大45度、表情式では表情の最大量までです。元からそれより大きいモデル設定は縮小しません。目線追従を使う場合は、カメラを見てキャリブレーションしてください。

### 距離による拡大・縮小

「動きの調整」の「近距離による拡大」「遠距離による縮小」で、近づいたときに大きくする強さと離れたときに小さくする強さを別々に調整できます。それぞれ初期値は0（オフ）、最大5倍の感度です。片方だけを有効にすることもできます。まず1〜2倍から試し、普段の距離でキャリブレーションしてください。基準距離から半分へ近づくと、感度1倍で表示は約2倍になります。

顔付近を中心に拡大し、手動ズーム・表示位置と組み合わせられます。距離による表示倍率は0.5〜4倍に収め、顔を見失うと元の表示へ滑らかに戻します。手動の表示設定やモデルの体格、揺れものの物理設定は変更しません。

### CPU・GPU

「アバター・出力」の「認識に使うデバイス」で選択して保存し、アプリを再起動すると反映します。初期値はCPUです。Windowsでは複数のGPUから1枚を選べ、描画にも同じGPUを使います。MacではCPUまたは対応する内蔵GPUを選べます。

## プレビューの操作

| 操作 | 動作 |
| --- | --- |
| 左または中央ボタンでドラッグ | 表示位置を上下左右に移動 |
| 右ボタンでドラッグ | カメラを回転 |
| ホイール／ピンチ | 拡大・縮小（最大20倍） |
| ダブルクリック／「最大化」 | プレビューを最大化・復元 |
| Esc | 最大化から戻す |
| 「初期位置に戻す」 | 移動・回転・拡大率をリセット |

Macでは「移動」をオンにすると、プレビュー上の2本指スクロールで上下左右へ移動できます。3本指操作はmacOS側の設定に依存します。

キャリブレーションは画面のボタンでも実行できます。Windowsでは他のアプリが前面でも右Ctrl／右Shiftを単独で押して離すと実行できます。Macではアプリが前面の右Control／右Shift、または⌘⇧Cを使います。

## カメラが見つからない・開始できないとき

- Webカメラが「USB 2.0 Camera」など、製品名と異なる名前で表示される場合があります。キャプチャーボードと取り違えないよう確認してください。
- 一度トラッキングを停止し、Windowsでは「一覧を更新」、Macでは「更新」を押して選び直します。
- 名前の照合が合わない場合は、明示的に「システム既定のカメラ」を選んで試せます。意図した機器が選ばれているか確認してください。
- OSのカメラ利用許可と、別アプリがカメラを使用していないかを確認してください。

入力は1280×720・最大30fpsを希望して取得し、実際の解像度・FPSを画面に表示します。機種・ドライバー・接続環境によって動作は異なります。

## 制限・データの扱い

顔・手・指の重なり、暗さ、画面外への移動で認識が不安定になる場合があります。腕・肘は推定による追従で、全身の精密なモーションキャプチャではありません。体の回転は頭の動きに連動します。揺れや表情はモデルに用意された設定によって結果が変わります。

VRMは200MB以下で、画像等を内包したファイルに対応します。外部URLを参照するモデルには対応していません。

カメラ映像の認識は同梱のMediaPipeを使い、端末内で行います。通常利用でカメラ映像をクラウドへ送信せず、音声入力は使用しません。Webカメラは手動で開始しますが、仮想カメラ／Syphon出力のオン・オフは前回の状態を復元します。

| OS | 設定の保存場所 |
| --- | --- |
| Windows | `%LOCALAPPDATA%/YuiTracking/settings.json`（ログは同じフォルダーの`app.log`） |
| Mac | `~/Library/Application Support/YuiTracking/settings.json` |

モデル自体は元の保存場所から読み込みます。

## ソースからのビルド

Windows版はC#／WinUI 3とWebView2、Mac版はElectronを使用し、描画・認識部分を共有しています。描画はThree.js／three-vrm、認識はMediaPipeです。

Windowsでは.NET SDK 8以降とNode.js／npmを用意し、リポジトリのルートで実行します。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build.ps1
```

インストーラーの作成にはInno Setup 6が必要です。`ISCC.exe`をPATHに追加するか、`.tools/InnoSetup/`へ配置してください。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-installer.ps1 -SkipAppBuild
```

Mac版の開発・パッケージ作成は [electron/README.md](electron/README.md) を参照してください。依存パッケージの初回取得にはインターネット接続が必要です。

共通処理のテストは `npm --prefix renderer test` で実行できます。Windowsのビルドスクリプトではカメラ選択・ショートカット・映像転送のテストも実行します。カメラ機種ごとの動作やトラッキング品質は、実環境での確認が必要です。

過去の実装・検証記録は [開発メモ](DEVELOPMENT-HISTORY.md)、公開版ごとの変更は [Releases](https://github.com/suzunayui/YuiTracking/releases) を参照してください。
