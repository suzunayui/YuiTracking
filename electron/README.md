# YuiTracking Mac版

Apple Silicon向けのMacアプリです。Windows版とVRM描画・顔・目線・上半身・手・指の認識処理を共有し、OBSへはSyphonでアバターと背景を出力します。

2026年10月19日時点のMac公開版は **2026.1019.1** です。[DMGをダウンロード](https://github.com/suzunayui/YuiTracking/releases/download/v2026.1019.1/YuiTracking-2026.1019.1-arm64.dmg)できます。Windowsのみの修正版がLatestになる場合があるため、Mac用ファイルが付いたリリースを選んでください。Intel Mac版は配布していません。

## 起動と操作

DMGを開き、YuiTrackingをアプリケーションフォルダーへコピーして起動します。現在の配布ファイルはアドホック署名で、Developer ID署名・Apple公証は付けていません。

1. 「VRMを開く」でモデルを選ぶか、同梱サンプルを選択します。
2. Webカメラを選び、「カメラを開始」を押します。macOSでカメラ利用を許可してください。カメラは自動では開始しません。
3. 正面を向いてカメラを見て、キャリブレーションします。
4. 「アバター・出力」「動きの調整」で背景、CPU／GPU、目線や動きの感度を設定します。

瞳への追従・カメラ目線・正面固定を切り替えられます。「目線の追従感度」は自分の瞳に追従する場合だけ有効です。「目の可動範囲」はカメラ目線でも1〜5倍で調整できます。モデルに目線の設定が必要です。

ホイール／ピンチで拡大縮小、左・中央ドラッグで移動、右ドラッグで回転します。「移動」をオンにすると2本指スクロールでも上下左右へ移動できます。3本指操作はmacOS側のドラッグ設定に依存します。ダブルクリック／最大化ボタンでプレビューを広げ、Escで戻せます。

キャリブレーションはボタン、アプリが前面なら右Control／右Shift単独、または⌘⇧Cで実行できます。

カメラ名が表示されない場合は「更新」で選び直してください。製品名と異なる名前で出ることもあります。「システム既定のカメラ」を明示的に選ぶと、カメラ名の照合を使わずに開始できます。使用する機器と画面のカメラ権限表示を確認してください。

設定は `~/Library/Application Support/YuiTracking/settings.json` に保存します。前回のモデル・背景・表示位置・動きの調整・Syphon出力のオン／オフを復元します。モデル本体は元の場所から読み込みます。認識は端末内で行い、音声入力は使用しません。

## 距離による拡大・縮小

「近距離による拡大」「遠距離による縮小」で、Webカメラへ近づいたときと離れたときの強さを別々に調整できます。それぞれ0はオフ、初期値も0です。普段の距離でキャリブレーションし、1〜2倍から試してください。顔付近を中心に拡大し、手動のズームと併用できます。

## OBSへのSyphon出力

1. YuiTrackingで「Syphon出力を開始」を押します。
2. OBSの「Syphonクライアント」（Syphon Client／Syphon Source）で、送信元 **YuiTracking** を選びます。
3. 緑背景を抜く場合はクロマキーフィルターを追加します。透過背景では透明度も送信します。

出力は1280×720・最大60fpsです。実際のFPSはモデルやMacの負荷によって変わります。操作画面・ファイル選択・実写カメラは出力に含みません。

SyphonはWeb会議アプリ等から選ぶ仮想カメラへの出力ではありません。配信中はYuiTrackingを起動したままにしてください。描画が途切れた場合は待機画像に差し替え、アプリ終了時に送信元を解除します。強制終了時の表示は受信側の挙動に依存します。

## 開発・パッケージ作成

Node.js／npmとXcode Command Line Toolsを用意し、リポジトリのルートから実行します。初回の依存取得にはインターネット接続が必要です。

```sh
cd renderer
npm ci
cd ../electron
npm ci
npm start
```

Mac上で次を実行すると、`dist/electron/` にarm64のDMGとZIPを生成します。

```sh
cd electron
npm run package:mac
```

開発用・配布用ともに、実Webカメラを自動で開始しないテストを用意しています。`electron/`で`npm test`を実行すると、描画・テスト映像での認識・設定復元・Syphon受信を確認します。配布用アプリはリポジトリのルートで次のように検証できます。

```sh
node tests/electron-smoke.cjs --packaged --gpu-recognition --vrm-picker
```

Apple Silicon Macでパッケージの起動、テスト映像の認識、設定の保存・再起動後の復元、Syphon送受信、署名・DMG整合性を確認しています。実Webカメラでのトラッキング品質や機種ごとの互換性は別途確認が必要です。
